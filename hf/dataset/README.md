# gomoku-15x15

15×15 无禁手五子棋（freestyle，五连及以上获胜）的训练数据集，**344,989 个局面**，每个局面带一枚策略标签和一枚胜负标签。

配套模型：

- 当前架构最终形态：[`w2Tao/gomoku-v1`](https://huggingface.co/w2Tao/gomoku-v1)（由在 `gomocup15.npz` 上训练的基线继续从 RAPFI25 主变蒸馏）。
- 历史基线：[`w2Tao/gomoku-baseline`](https://huggingface.co/w2Tao/gomoku-baseline)（只用这两个文件训练出来的策略网络，对冻结启发式 63.0%；旧建库上的历史 run 是 65.5%）。

代码：[github.com/w2Tao/gomoku](https://github.com/w2Tao/gomoku)。

## 内容

| 文件 | 大小 | 内容 |
|---|---|---|
| `gomocup15.npz` | 2.58 MB | 344,989 个局面，来自 12,614 局引擎对局（去重后 11,838 个 `game_id`） |

## `gomocup15.npz`

| 字段 | 形状 | 含义 |
|---|---|---|
| `own` | (N, 4) uint64 | 落子方棋子的位棋盘 |
| `opp` | (N, 4) uint64 | 对方棋子的位棋盘 |
| `last` | (N,) int16 | 对手最后一手的格子号，空盘为 −1 |
| `ply` | (N,) uint8 | 盘面棋子数 |
| `cls` | (N,) uint8 | 0 负 / 2 胜（无和棋） |
| `move` | (N,) int16 | 该局面下引擎实际下的一手 |
| `value_target` | (N, 3) float32 | one-hot，列序 `[负, 和, 胜]` |
| `value_weight` | (N,) float32 | 恒为 1 |
| `game_id` | (N,) int64 | 用于按对局切分 |
| `is_val` | (N,) bool | 验证集标记（按对局切，10%） |
| `meta` | 标量 | JSON 字符串 |

**位棋盘打包**：225 位装不进两个 uint64，所以用 4 个 64 位字，小端。
解包：`sum(int(row[i]) << (64*i) for i in range(4))`。

**规范形式**：每个局面以「轮到走棋的一方」为视角。颜色不出现在表示里。

## 来源

数据由 [Gomocup](https://gomocup.org/) 2026 的 **freestyle 15×15 联赛**棋谱转换而来。该联赛的规则与本数据集完全一致（15×15、五连及以上、无禁手），参赛的是 RAPFI、KATAGOMO、ALPHAGOMOKU 等世界顶级引擎。

原始棋谱 12,984 局，转换后保留 **12,614 局（97.2%）**，丢弃的 370 局是非法着法或没有以五连结束的。建库时按「局面 + 着法 + 手数 + 胜负」去重：516,861 → **344,989**（−33.3%）；同时补回了空盘局面。去重会把整局重复的对局全部合并，所以文件里实际只有 **11,838 个不同的 `game_id`**，而 `meta.games` 记录的是去重前的 12,614 局。

胜负标签是**精确的**——每局赢家已知，所以局内每个局面都直接得到「落子方最终是否获胜」，不需要任何 rollout。

转换脚本见本仓库 `code/build_gomocup_dataset.py`。

## 注意

1. **开局多样性差。** 每个联赛只有 12 个固定开局，所以前几手会在几千局里重复。中盘和残局是多样的。去重同时丢掉了频次信息（空盘现在只有 10 行而不是约 7,600 行），这可能比去噪带来的好处更重要；`--dedupe 0` 可以恢复旧行为。
2. **标签是引擎的策略化胜负**（`V^π`），不是博弈论最优值 `V*`。不过引擎远强于本项目自产的任何对局者。
3. **无和棋。** 只保留了以五连结束的对局。
4. **许可证**：原始棋谱来自 Gomocup，该站点**未声明许可证**。本数据集是其派生作品，使用前请自行确认合规性。如果这一点对你有影响，请不要把它用于商业用途。

## `teacher15.npz`

同样的 schema，但局面来自本仓库冻结的规则型启发式自博弈（启发式 vs 启发式，前 4 手随机开局）。标签是**启发式自己会下的那一手**加上该局的胜负。它比 `gomocup15.npz` 弱得多——用途是提供先验，不是提供强度。
